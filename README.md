# 量子コンピュータ・ディスコ(非公式リメイク)

DJ体験を通じて量子コンピュータの原理を学べるWebアプリです。
日本科学未来館の常設展示[「量子コンピュータ・ディスコ」](https://www.miraikan.jst.go.jp/exhibitions/future/qcdisco/)に着想を得た**非公式のファンリメイク**であり、展示の素材・楽曲・プログラムは一切使用していません。音楽はすべて Web Audio API でブラウザ内合成しています。

## 遊び方

3つの量子ビット(q0, q1, q2)が8曲のレコードに対応します(2進数 `000`〜`111` が曲番号)。
DJブースの盤面に円形のゲートトークンを置いて量子回路を組むと、その場で音が変わります。

| ゲート | はたらき |
|---|---|
| **X** | ビット反転。曲を選ぶ |
| **H** | 重ね合わせ。複数の曲が同時にミックス再生され、音量が出現確率に対応する |
| **R** | 位相回転(タップで角度切替)。確率は変えないが、干渉と組み合わせると確率を操れる(例: H→R(π)→H は X と同じ) |
| **CNOT (●)** | 制御反転。「もつれ」を作る(フリー/上級課題で使用可) |
| **M** | 観測。確率に基づいて1曲がランダムに選ばれ、ダンスフロアに流れる(波束の収縮) |

### コース

- **レッスン** — 8ステップのチュートリアル。X → 観測 → 重ね合わせ → 位相 → 干渉の順に学ぶ
- **トライ** — 7つの課題に挑戦(「Xを使わずに曲011を100%に」「もつれで2曲だけを50/50に」など)
- **フリー** — 全ゲート・15ステップの自由プログラミング

ここで使うゲート記号は、実際の量子コンピュータのプログラミングでもほぼそのまま使われているものです。

## ローカルで実行

ビルド不要の静的サイトです。ESモジュールを使っているため、HTTPサーバー経由で開いてください。

```sh
python3 -m http.server 8000
# → http://localhost:8000 をブラウザで開く
```

## GitHub Pages で公開

リポジトリの Settings → Pages → 「Deploy from a branch」で `main` ブランチ・`/ (root)` を選ぶだけで公開できます。

## 技術メモ

- 依存ライブラリ・CDN・外部音源なし(バニラ JS + Web Audio API + Canvas)
- 量子状態は8次元複素状態ベクトルで厳密にシミュレート(`js/quantum/`)
- 8曲は 120BPM・4小節・Aマイナーペンタトニックに統一して OfflineAudioContext で事前レンダリングし、8本のループをサンプル精度で同期再生。各曲の音量は振幅の大きさ |a| に追従(等パワーミックス)
