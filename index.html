ゲート
CX・CCX は置いた場所が X(反転される行)。縦線の先の C = 制御で、その行が 1 のときだけ X が反転する(CX は C 1つ、CCX は C 2つ)。
トークン: ドラッグで配置/移動、盤外へドラッグか右クリックで削除。R はタップで角度切替、CX はトークンか C マーカーをタップで制御の行を切替、その他はタップで削除。
空きマスからドラッグすると範囲選択でき、選択したゲート(白い点線枠)はまとめてドラッグで移動できる。空きマスをタップで選択解除。
日本科学未来館の常設展示「量子コンピュータ・ディスコ」に着想を得た非公式ファンリメイクです。展示の素材・楽曲は一切使用していません(音楽はすべてWeb Audio APIで合成)。
